# Unser Kleingarten

Gartenplan, Pflanzen, Aufgaben und Fotos als installierbare Web-App (PWA).

- **App:** `index.html` – läuft über GitHub Pages
- **Daten & Fotos:** Supabase (Tabelle `docs`, Speicher `fotos`) – Einrichtung: `supabase/setup.sql`
- **Zugangsdaten:** `js/config.js`
- **Ansehen** geht für alle mit dem Link, **bearbeiten** nur nach Anmeldung. Konten werden in Supabase unter Authentication → Users angelegt.
